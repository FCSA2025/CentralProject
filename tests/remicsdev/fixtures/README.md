# TSIP parm samples for parity tests

`tsip-parm-samples.tsv` is generated by:

```powershell
.\scripts\Export-TsipParmSamples.ps1
```

Run automated parity tests:

```bash
node tests/remicsdev/tsip-validation-parity.test.js
node tests/remicsdev/tsip-db-report-parity.test.js
```

The first test covers classic bitmask weights, loss rules, validation, BuildParmParm, and a full real run (`frse.tp_agginttest_parm` run `1`).

The second test round-trips report values from live remicsdev DB samples.
