Getting Started

Field labels Green = required. Black = optional. Red italic = key (call sign / location). Blue italic = calculated or locked.
Lookups ? opens a code list for that field. ?? looks up an Operator. Find… searches your SDF antenna or equipment catalogues (or main).
TS Data Files Terrestrial microwave files. Right-click the tree root to Create new file or Import a txt file. Right-click a file to Validate, Edit, PCN, or DbUpdate.
ES Data Files Earth-station files. Same tree actions as TS. Use Azimuths when you need off-axis or satellite pointing records.
SDF Files Your company catalogues (antennas, equipment, operators, notes, towers). Pick a type, then Create new or expand an existing file.
Typical first jobs Create or import a file → add Title / Site / Antenna → Validate → fix errors → PCN or Database Update.
Create vs Import Create starts an empty file. Import loads a txt dump (from Export). Confirm overwrite if that name already exists.
Project Code The header dropdown is the company workset (schema project), not the file name. Files you create live under the selected project. If a file you just created is missing, check the dropdown.
Enter key On forms, Enter moves to the next field (same as Tab). Click Save to store the record.
Hop (TS) A hop is local call sign + remote call sign + band. Azimuth, elevation, and distance stay blank until both sites exist.
SDF first Antenna and equipment codes come from your SDF files (or main). If Find… is empty, create or import SDF Ante / Eqpt first - do not type a manufacturer name into the code field.
Validate fails Open Display Results. Common first-job errors are listed below.

Terms

TSTerrestrial (point-to-point microwave) data file
ESEarth station data file
SDFSubsidiary data file (antenna, equipment, operator, and other catalogues)
PCNPrior Coordination Notice - email operators that may be affected
DbUpdateSend a clean, validated file to FCSA for the coordination database
TSIPInterference study jobs. Queue and reports are under TSIP in the left nav
ValidateMust pass (no errors) before PCN or Database Update
